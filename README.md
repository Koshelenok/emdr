# emdr

Первая версия приложения **emdr** из репозитория [github.com/Koshelenok/emdr-react](https://github.com/Koshelenok/emdr-react), собранная на песочнице [CodeSandbox](https://codesandbox.io).

Приложение представляет собой простой тренажёр для EMDR-терапии: по экрану движется шарик, скорость и длительность движения настраиваются перед запуском.

## Запуск

```bash
npm install
npm start
```

Сборка проекта:

```bash
npm run build
```
